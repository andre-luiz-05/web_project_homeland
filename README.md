# Tripleten web_project_homeland

## Tecnologias e técnicas utilizadas

- HTML5, usando tags semânticas como `header`, `main`, `section` e `footer`
- CSS3, com os estilos separados em vários arquivos e importados no arquivo principal
- Metodologia BEM para nomear as classes CSS (bloco, elemento e modificador), mantendo um arquivo CSS separado para cada bloco da página
- Flexbox para alinhar alguns elementos, como o logo no topo da página
- Media queries para deixar o layout responsivo em diferentes tamanhos de tela
- normalize.css, para os elementos ficarem parecidos em navegadores diferentes
- Fonte Inter, com fontes do sistema como alternativa caso ela não carregue
